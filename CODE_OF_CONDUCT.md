# Code of Conduct

Rudder contributors and maintainers are expected to keep project discussions professional, technical, and respectful.

## Expected Behavior

- Be direct and constructive when discussing code, operations, and design tradeoffs.
- Keep feedback focused on the work, not the person.
- Respect that networking and eBPF work often involves production-sensitive details.
- Avoid sharing private topology, packet captures, credentials, or host information in public threads.

## Unacceptable Behavior

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing private security details before maintainers have had a chance to respond.
- Repeatedly derailing issues or pull requests away from the technical topic.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests; or block users when needed to keep the project safe and useful.

Report conduct concerns through the repository maintainers. Report vulnerabilities through the private process in [SECURITY.md](SECURITY.md).
